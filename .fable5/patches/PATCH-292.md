## Facts (CTO-checked)
- The AntV catalogue (`lib/ai/antv/catalog.data.ts`, @antv/infographic 0.2.20) has 276 templates in 7 categories:
  chart, list, sequence, hierarchy, compare, quadrant, relation. The library ships 74 of them
  (`ANTV_LIBRARY_TEMPLATES`, `libraryTemplates.ts`), 2.30 MB raw / 180 KB gzipped.
- 202 are missing; 20 of those are `*-animated-*` variants (`relation-dagre-flow-*-animated-*`,
  `sequence-interaction-*-animated-*`): motion that a still drawing cannot show. 182 remain.
- With the PATCH-282 name rule, all 256 non-animated templates have unique names (checked: no duplicate, with or
  without the section prefix).
- The 276-design converter audit (PATCH-281) converted all 276; only 3 lose anything (3 % pattern stripes).
- `ANTV_LIBRARY_TEMPLATES` is imported only by the dev export view (`AntvExcalidrawHarness.tsx`) and tests — never by
  the app bundle — so deriving it from the catalogue costs the app nothing.
- Chart values (`chartValues/data.ts`) supports 7 chart templates. The two new pie styles
  (`chart-pie-donut-compact-card`, `chart-pie-plain-text`) use the same AntV pie renderer and role tagging as the four
  supported pies. `chart-wordcloud-rotate` is a word cloud, like `chart-wordcloud`, which has no values to edit.
- Estimated new file size ≈ 8 MB raw (≈ 31 KB per design), ≈ 600 KB gzipped. Excalidraw's library menu renders
  thumbnails in batches while scrolling.
- CTO decision: ONE file, not the two the owner was offered. A second file means a second loader path in both editors
  (`DrawingEditor.tsx`, `DrawingLayout.tsx`, both over the size ceiling) for a gain that only matters if loading is
  slow. The live check measures it; if the library takes more than 1.5 s longer to appear than today, an addendum
  splits the file.

## Design
1. **The list** (`lib/ai/antv/toExcalidraw/libraryTemplates.ts`):
   - Keep the 74 curated picks exactly as they are, renamed `ANTV_LIBRARY_PICKS` (same `BY_SECTION` data, same
     order).
   - `ANTV_LIBRARY_TEMPLATES` = for each section in the existing order (Charts, Lists, Steps & timelines,
     Hierarchies & mind maps, Comparisons, Relations): that section's picks first, then every other catalogue
     template of that section in catalogue order (`ANTV_TEMPLATES` order), skipping any template whose id contains
     `-animated-`.
   - Section of a catalogue template, by `category`: chart → Charts, list → Lists, sequence → Steps & timelines,
     hierarchy → Hierarchies & mind maps, compare and quadrant → Comparisons, relation → Relations. An unknown
     category throws at module load (a future catalogue must not slip in silently).
   - `name` by the existing `libraryTemplateName` rule. Update the file's header comment (no longer "at most 6 per
     family").
2. **Edit values for two more pies** (`lib/ai/antv/chartValues/data.ts`): add `chart-pie-donut-compact-card` and
   `chart-pie-plain-text` to `ANTV_CHART_TEMPLATES` (now 9); update the "7" comments. Nothing else in chartValues
   changes. The export view already attaches chart data to every template `isAntvChartTemplate` accepts.
3. **The file** `public/libraries/antv-diagrams.excalidrawlib`: regenerated by the CTO from the export view
   (`/e2e-fixtures/antv-excalidraw?export=library`). New budget: ≤ 9 MB raw, ≤ 900 KB gzipped. The coder does not
   generate it.
4. Nothing else changes: the loader, both editors, the export view and the serialiser stay as they are.
